# Scripts

Utility scripts for MiniHog project management.

## Available Scripts

- `ADD_ENV_VARS.sh` - Helper script to add environment variables to Vercel projects
- `update-cors.sh` - Script to update CORS_ORIGIN in Vercel

## Usage

Most scripts require you to be in the appropriate package directory:

```bash
# Example: Add environment variables
cd packages/api
../scripts/ADD_ENV_VARS.sh
```
