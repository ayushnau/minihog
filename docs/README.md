# MiniHog Documentation

This directory contains all documentation for the MiniHog project.

## 📁 Directory Structure

### `/deployment`
Deployment guides for different platforms and configurations:
- `DEPLOYMENT.md` - General deployment guide
- `DEPLOY_VERCEL_SUPABASE.md` - Vercel + Supabase deployment
- `DEPLOY_SUPABASE_VERCEL.md` - Alternative Supabase + Vercel guide
- `QUICK_DEPLOY.md` - Quick deployment steps
- `SUPABASE_SETUP.md` - Supabase database setup
- `VERCEL_SUPABASE_ENV_VARS.md` - Environment variables reference

### `/setup`
Setup and installation guides:
- `SETUP.md` - Local development setup

### `/troubleshooting`
Troubleshooting guides and fixes:

- `FIX_CORS.md` - CORS troubleshooting
- `USER_BASED_EVENTS_IMPLEMENTATION.md` - User-based event filtering implementation
